# Required tools for the Geurts Game Forge God contract

Version 0.5.1 requires separately installed, licensed Odin Inspector and Quantum Console assemblies. Validation uses Unity 6000.3.22f1, Odin Inspector 4.0.2.4 and Quantum Console 2.6.7. Neither commercial asset is included in this package, and no unsupported registry dependency is declared.

Run `GeurtsGameForge.Documentation.Status` in Quantum Console during an Editor development session to inspect the package and documentation update status. The command is read-only and lives entirely in the Editor assembly. This package remains independent of God and available without Diagnostics; the dashboard's design and update lifecycle are unchanged.

This change implements the user's mandatory-tool requirement, which supersedes older zero-tool companion notes in historical documentation. It does not update the project-local authoritative documentation snapshot automatically.
